# مصادر الأصول الفنية

جميع الصور المستخدمة من موقع [Kenney.nl](https://kenney.nl) برخصة **CC0** (ملك عام، استخدام تجاري وغير تجاري حر بالكامل بدون أي اشتراط):

- Scribble Platformer Pack — البلاطات (عوائق/عملات/جواهر/قلوب)، الخلفيات، التأثيرات
- Platformer Characters Pack — شخصيات اللاعبين (وضعيات: وقوف/قفز/انحناء/مشي/إصابة/احتفال)
- UI Pack — الأزرار والنجوم والأيقونات
- UI Audio — أصوات نقر القائمة

أصوات اللعب (قفزة/جمع/اصطدام/فوز/موسيقى خلفية) مُولَّدة برمجياً داخل الكود عبر Web Audio API (بدون ملفات خارجية)، لضمان عدم وجود أي إشكال ترخيص وحجم أصغر للمشروع.
