# 🦸 قفزة الأبطال

لعبة أطفال يتحكم فيها الطفل بحركات جسمه الحقيقية أمام كاميرا Mac — بدون لوحة مفاتيح ولا يد تحكم. الطفل يقفز، ينحني، يتحرك يمين/يسار، يدور، يرفع يده — والشخصية على الشاشة تنفّذ نفس الحركة فوراً.

كل شيء يعمل **محلياً بالكامل** على جهاز Mac: لا يوجد رفع فيديو لأي سيرفر، ولا اتصال إنترنت وقت اللعب (بعد التثبيت لأول مرة).

## كيف تشغّل اللعبة

```bash
cd "/Users/mac/Desktop/أردوينو/المشاريع والكتب/qafzat-alabtal"
npm install
npm run dev
```

ثم افتح الرابط اللي يظهر بالتيرمينال (عادة `http://localhost:5173`) بمتصفح **Chrome**، واسمح للمتصفح باستخدام الكاميرا عند الطلب.

## تشغيل الاختبارات الآلية

```bash
npm test
```

56 اختبار يفحصون منطق اللعبة كاملاً (كشف الحركة، التصادم، النقاط، الصعوبة، الزعيم...) بدون الحاجة لمتصفح.

## الحركات المدعومة

| الحركة | الحدث |
|---|---|
| قفز | `VISION_JUMP` |
| انحناء | `VISION_DUCK` |
| تحرك يسار | `VISION_LEFT` |
| تحرك يمين | `VISION_RIGHT` |
| دوران | `VISION_TURN` |
| رفع يد | `VISION_RAISE_HAND` |

## التقنيات المستخدمة

- **TypeScript + Vite** — بناء سريع، آمن من الأخطاء
- **Phaser 3** — محرك اللعبة
- **MediaPipe Tasks Vision (Pose Landmarker)** — الرؤية الحاسوبية، يعمل محلياً بالكامل بالمتصفح (WASM)
- **Kenney.nl** (رخصة CC0) — الأصول الفنية، راجع `public/assets/CREDITS.md`

## للتفاصيل الكاملة

- `PLAN.md` — خطة البناء الكاملة وحالة كل مرحلة
- `CLAUDE.md` — ذاكرة المشروع والقرارات التقنية المقفولة
